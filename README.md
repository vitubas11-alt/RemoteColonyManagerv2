# Remote Colony Manager

Mod para **Minecraft 1.20.1 (Forge 47.2.0)** que adiciona um painel remoto para o **MineColonies**:
gerencie ordens de construção, construtores e prédios sem precisar estar perto da colônia.

## Recursos
- Painel com tema escuro, listas com rolagem e resumo da colônia
- Atribuição **manual** e **automática** (maior nível da cabana, depois o mais próximo)
- Botão "Atribuir TODOS" para ordens livres
- Aba de prédios: Construir, Evoluir, Reparar e Remover (com confirmação), com busca e filtros
- Abrir pelo item, tecla **K** ou comando `/rcm`

## Requisitos
- Minecraft 1.20.1, Forge 47.2.0+
- MineColonies 1.1.1317+

## Compilar
```bash
./gradlew build
```
O JAR sai em `build/libs/remotecolonymanager-0.3.0.jar`.

## Download
Veja a aba **Releases** ou os artefatos em **Actions**.
